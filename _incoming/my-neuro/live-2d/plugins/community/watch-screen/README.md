# watch-screen · 程序器官 v1

> 设计依据：`docs/实时旁观-程序器官设计.md`
> 一句话：**像素只进「器官」，主对话只读语言化摘要**——这是 token 能省下来、又能"陪你实时看"的关键。

## 它解决什么

旧版 watch-screen 是「每 2 秒截一张，攒 5 张，主动时把 5 张图塞进 LLM」：

| | 旧版 | 本版（器官模式） |
|---|---|---|
| 输入 | 定时截图，不看变化 | **2fps 采样 + 帧差/直方图变化检测**，只留"变了"的关键帧 |
| 记忆 | 最近 5 张图，没有时间感 | **120 秒环形滚动摘要**，每帧一句「什么/在做什么/氛围」+ 时间戳 |
| 进主对话的东西 | 5 张图（很贵） | **一段纯文本摘要**（默认 60 秒窗口，约 60~120 token） |
| 工具 | 无 | `look_now()` / `recall_last(seconds)` / `find_moment(keyword)` |
| 主动开口 | 每凑满 5 帧就发一次 | **显著变化 + 距上次开口 > 90 秒 + 不在说话** 才允许 |
| 无多模态模型 | 直接发图，模型看不懂就瞎猜 | **自动降级**：30 秒一帧 + 时间戳，摘要/工具照常可用 |

## 文件

- `index.js` —— 插件本体：采样循环接 `ipcRenderer.invoke('take-screenshot')`、32×18 灰度签名、三个工具、被动注入、主动开口、旧版行为开关。
- `vision-organ.js` —— 纯逻辑器官（不依赖 DOM/electron，可在 node 里单测）：变化检测、关键帧、环形缓冲、工具、降级、统计。

## 配置（plugin_config.json，全部可选）

| key | 默认 | 说明 |
|---|---|---|
| `useVisionOrgan` | `true` | `false` = 回到旧版「最近 5 张图」行为（A/B 对比用） |
| `passiveMode` | `true` | 用户说话时注入"最近 60 秒摘要"（器官模式只有文字，不塞图） |
| `activeMode` | `true` | 允许主动评论（仍受 90 秒门控） |
| `organSampleIntervalMs` | `500` | 采样间隔（2fps） |
| `organRingSeconds` | `120` | 环形缓冲时长 |
| `organMaxEntries` | `240` | 缓冲条数上限 |
| `organProactiveMinGapMs` | `90000` | 两次主动开口最短间隔 |
| `organFallbackIntervalMs` | `30000` | 降级模式的关键帧间隔 |
| `organSummaryMaxChars` | `60` | 单条摘要最长字数 |
| `captureInterval` / `maxFrames` | `2000` / `5` | **仅旧版**参数 |

## 三个工具（LLM function calling）

| 工具 | 返回 | 用途 |
|---|---|---|
| `look_now()` | 当前一句 + 时间 + 是否有帧（调用后下一轮对话会附带那一帧） | "现在屏幕上是什么" |
| `recall_last(seconds=60)` | 纯文本摘要（带时间戳）+ token 估算 | "刚才发生了啥"（最省 token 的路） |
| `find_moment(keyword)` | 匹配到的时间点／摘要（最多 5 条） | "刚才那个报错在哪一秒" |

主动开口只在 `kind === 'scene'`（换场景级别）时触发；`change`／`quiet` 不打扰。

## 降级策略

1. 解析不到多模态模型（`config.vision.provider_id` 或 `config.llm.provider_id` 都解析不出 provider），或摘要调用抛错/空返回
   → 标记 `fallbackMode`，**不再反复调用**（省额度），改为每 30 秒留一条 `HH:MM:SS 画面…`；
2. 截图失败 → 采样间隔指数退避（最多 5 秒），不拖死主线程；
3. 摘要与上一条完全相同 → 丢弃（`dropped` 计数），避免刷屏。

## 为什么只读摘要不吃像素（设计文档的结论）

1. **视觉 token 剪枝**（PruneVid, arXiv:2412.16117）：视频冗余极大，按变化/按问题选帧能砍 80% token；
2. **流式自我视频助手**（arXiv:2506.05904）：要做事件检测，而不是逐帧描述；
3. **何时主动开口**（Vinci2, arXiv:2607.11523）：主动助手的核心是"什么时候该说"——本插件用"显著变化 + 90 秒冷却 + TTS 忙时不插嘴"回答；
4. **程序器官路线**（arXiv:2310.08803 / arXiv:2603.03148）：器官负责把像素编码成语言可推理的表示，LLM 只吃语言。

## 隐私

- 截图只在内存里转成 32×18 灰度签名后立即丢弃原图；只有关键帧会短暂保留（默认最多 6 张），用于 `look_now` 取图。
- 摘要只在本机滚动缓冲里，`clear()` 可随时清空；不会写入磁盘。

## 实测（2026-10-31，本机 60 秒）

本机没有配多模态 provider，所以真实跑的是**降级路径**：60 秒 2 条时间戳锚点、关键帧率 0.033/s、
主动开口 0 次、最近 60 秒摘要 16 token、截图错误 0、摘要器失败 1 次后不再重试。
同一份 `vision-organ.js` 的 **2fps 正常路径**用注入式 60 秒仿真验证：120 次采样 → 3 条关键帧（0.05/s）、
3 条中文摘要、约 76 token；换场景 + 距上次开口 >90s + 不在 TTS 时允许主动开口。
完整记录见 `_incoming/probe/b4-live-60s.md`。
