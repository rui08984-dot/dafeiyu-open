大肥鱼 · 安装说明（Windows 10/11 x64 · v0.5.2）

1) 启动
   双击桌面「大肥鱼」。第一次启动约 5–15 秒（皮套 16MB 模型要加载）。

2) 第一次用：填 API Key
   启动后会自动弹出设置窗的「模型」页：
     · 接口地址：默认 https://api.openai.com/v1
     · API 密钥：填你自己的 key
     · 模型：默认 gpt-4o-mini
   填好点右下角「保存」，立刻生效，不用重启。
   支持任意 OpenAI 兼容网关（OpenAI、DeepSeek、硅基流动、本地 Ollama…），
   把接口地址和模型名改成对应值即可。

3) 语音
   本安装包已带 edge-tts（联网访问微软免费语音端点，不需要密钥）。
   想换音色/引擎：设置窗「模型 → 语音」；也支持 OpenAI 兼容 /audio/speech。

4) 完整能力（推荐装）：长期记忆 / 按住说话 / 一起看 / 语义表演 / 声纹 / 本地模型
   底座只带「她本人」；Python 侧器官做成组件，按需下载（模型走国内镜像，SHA256 校验）：
     · 第一次打开设置时，会弹「把她的完整能力装上？」——8 个组件全部默认选中，
       点「全部安装」一次装好；也可以点「稍后」，之后到「设置 → 组件」再装
     · 或双击安装目录里的 安装组件.cmd install --all
   装完重启大肥鱼生效。8 个组件合计约 5.5GB；本地视觉（ollama）的三个模型另需
   约 9.3GB，请按 ≥16GB 空闲磁盘准备（ollama 拉模型前还会再查一次 ≥12GB）。组件包括：
     · python：服务共用的独立 CPython 运行时（69.7MB）
     · memory：MemOS 长期记忆 + Qdrant + 嵌入模型（707.4MB，ModelScope）
     · voice-asr：SenseVoice 按住说话（263.8MB，hf-mirror）
     · cowatch：一起看（系统声音回环，12.5MB）
     · lumen：LumenAct 语义表演（203.0MB，hf-mirror）
     · voiceprint：声纹嵌入（263.5MB，CPU 推理）
     · local-memory：MemOperator-4B 本地记忆模型（2,381.6MB，CPU 推理；
       复用 memory 组件的 llama.cpp，依赖 memory）
     · ollama：便携 Ollama（1,637.8MB；qwen3-vl / glm-ocr 等模型约 9.3GB
       在安装时按需拉取；paddleocr-vl 非官方 registry，属可选档）
   组件目录在安装目录的 components\，删掉对应文件夹即可卸载（或
   安装组件.cmd remove --id=...）。

5) 想让她主动开口
   安装版默认「静默模式：开」（只回应、不主动搭话，避免没配 key 时刷报错）。
   填好 key 后，在托盘右键菜单里把「静默模式」关掉即可。

6) 浏览器标签感知（可选）
   安装目录的 浏览器扩展\browser-tabs\ 是 Chrome/Edge 的 MV3 扩展：
   打开浏览器 → 扩展管理 → 开发者模式 → 「加载已解压的扩展程序」→ 选中该目录。
   不装不影响桌宠本体，只是读不到浏览器标签页。

7) 数据与卸载
   配置、记忆、组件都在本安装目录（卸载不会删除）。
   卸载：Windows 设置 → 应用 → 大肥鱼。

8) 已知限制
   · 未装组件时：按住 V 说话 / 长期记忆 / 一起看 / 语义表演 / 声纹不可用（其余照常）。
   · local-memory 与 ollama 是 CPU 推理；全部装完约 15.8GB，请按 ≥16GB 空闲准备。
   · 看屏、窗口操控、UIA 走随包的 Rust 内核（pet-core），始终可用。
   · 安装包未代码签名，Windows SmartScreen 可能提示「未知发布者」，选择「仍要运行」。
