# v0.5.2 · 首启引导「全部安装」（Windows）

**底座与 8 个组件和 v0.5.1 完全一致**（组件包沿用 v0.4.0 / v0.5.0 资产，哈希未变）；
本版只改第一次启动的引导，外加一条 RSS 投递缓存修复。

## 安装

1. 下载 `DaFeiyu-Setup-0.5.2.exe`（**125,168,708B / 约 119.4MB**，sha256 `77ab5e4d…4ca8a438`），双击安装。
2. 启动「大肥鱼」：第一次会同时看到「模型」页和 **「把她的完整能力装上？」** 弹窗。
3. 弹窗里 **8 个组件全部默认选中**，点「全部安装」就一起下（应用内走国内镜像，断点续传 + SHA256 校验）；
   也可以「稍后（先填 key）」，之后到「组件」页随时再装。
4. 装完重启大肥鱼生效。

## 本版新增：首启引导

- **全选、一键**：不做推荐档位/勾选，8 个组件全部「已选中」，点一次全部安装。
- **提前说清代价**：合计约 5,539MB；本地视觉（ollama）三个模型另需约 9.3GB；
  提示磁盘 ≥16GB、8B 视觉模型 8GB 以上显存更流畅（显存不足自动走 CPU）。
- **只提示一次**：弹过即记在 userData，点「稍后」也不会反复弹；组件页仍可随时安装。
- **只在安装版生效**：开发树不弹；与填 key 并行，装组件不阻塞聊天。

## 修复

- `world-extras` 的 JSON 缓存只按 `mtimeMs` 失效：同一毫秒内 `rss-brief.markDelivered`
  重写后仍会读到旧 `picked`，导致 RSS 第三轮投递偶发 0 注入（单测 6/10 偶发红）。
  改为 **mtime + size 双键**；修复后 10/10 通过。

## 已知限制（与 v0.5.1 相同）

- 安装包未代码签名，SmartScreen 会提示「未知发布者」。
- 全部装完约 15.8GB（组件 5.5GB + 本地视觉模型 9.3GB）；磁盘不足时 ollama 组件会明确报错。
- 卸载不撤销组件 setup 写入的 provider/MemOS 指向（P1）。
- 安装版不提供 dev 维护脚本与舞台调试页。
