## P0 · 快赢（每项 ≤半天，效果立现）

### 1. 她的日记 ⭐ 拟真杀手锏
- **依托**：memory-evolve 巩固日志 + 情绪弧线 digest + 事件卡（都已存在）。
- **做什么**：每天 00:30 把当天的「巩固日志 + 弧线 + 共看事件卡」合成一篇**第一人称日记**写进
  `data/日记/2026-11-07.md`（"今天他让我生气了两次，但后来陪我看了剧……"）。
  静默版只攒素材不生成（零 API）；活泼版每天一次 LLM 调用。第二天聊天时她**自然引用自己的日记**。
- **为什么世界级**：竞品的记忆是数据库行；她的是**有心情的日记**。被听见感（feeling heard）论文
  的最强形态——她不只是记得，她**回味**。

### 2. viseme 口型（第五轮论文 Top3）
- **依托**：Edge TTS WordBoundary 时间戳（现成）+ 口型增益管线。
- **做什么**：时间戳→按字素查元音表（a/i/u/e/o → 口型宽度/高度曲线）→ 驱动 ParamMouthForm，
  口型从「能量开合」升级到「有形状」。
- **为什么**：拟真短板里最「看得见」的一个；我们握有 TTS 前文本这个学界都没有的优势。

### 3. 回话价值打分器（第五轮 Top2）
- **依托**：watch-screen 联络表 + 主动搭腔闸门。
- **做什么**：主动开口前打分「情绪强度 × 相关性 × 新鲜度」，低于阈值就憋住——
  从「见条就回」升级为「该说话才说话」（Jarvis 97% 沉默哲学）。

## P1 · 大件（月级，各有明确设计）

### 4. 桌面主播模式（Neuro 心跳）
- dawn-dusk-line 升级为**编播器**：无对话时段自主排节目单（问候→表演→聊记忆→陪你干活→晚安），
  每段节目=一次演出编排+一段说话，全部走既有管线；面板可关。
- **世界级点**：不是「定时弹消息」，是**有节目感的连续演出**。

### 5. 游戏陪玩官
- **依托**：RapidOCR（本机已有）+ watch-screen 采样 + 耳机耳朵。
- **做什么**：识别屏幕上的关键事件（击杀/死亡/血条告急/胜利）→ 主动战术吐槽
  （"又送？我看着都急" / "这波团打得漂亮"）。游戏期禁弹窗铁律由静默闸门管。
- **世界级点**：市面「游戏陪伴」全是语音助手接命令；她是**真看懂了画面再开口**。

### 6. 记忆图谱面板
- MemOS 图谱已开（doctor 显示「图谱 开」）——把关系图渲染进面板记忆页，
  节点=记忆条目，点节点=让她的相关回忆直接进对话。回忆从检索变成**可浏览的脑内世界**。

### 7. 快慢双轨应答（第五轮论文强度最高项）
- Latency-Cover 架构：第一轨 300ms 内短反应（"哈？"点头动作）垫场，第二轨完整回复接管。
- 动管线（tts-processor + LLM 流），等 3 号打分器验证后上。
