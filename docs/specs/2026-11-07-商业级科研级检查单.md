# 大肥鱼 · 商业级/科研级对标检查单（2026-11-07）

> 目标：把项目从「很强的工程原型」推到「可发行的商业产品 + 可发表的研究平台」。
> 依据：2026 市场实测（Steam AI 桌宠 $12.99/份、itch.io $12.90 一次性买断为主流）+
> 隐私合规基准（AI 伴侣应用隐私调研：屏幕监控须披露、本地优先是加分项、导出/删除权是 2026 标配）+
> 科研评估基准（RealCompanion arXiv 2610.01780 纵向评测；ImpactBench 807 指标）。

## A. 市场定位（联网实测）

- **直接竞品**：AI Desktop Pet（Steam 2026-04，$12.99，本地 LLM+语音克隆+视觉小说模式，约 $17k 总收入）——
  它没有：真情绪状态总线/一起看/游戏直控/主播陪玩 OCR。
- **定价形态**：$12~13 一次性买断是主流；订阅制被用户骂（Desktop Mate 因「用自己的模型还要收费」翻车）；
  「free and unlimited AI」是漏斗——推理成本总要在别处收回 → 我们的正确姿势：
  **买断制 + 用户自带 API Key**（我们的 TTS/LLM 四后端适配层正好是卖点：接谁的 key 用户自己选）。
- **渠道**：Steam 有 Desktop Companion 专门品类；itch.io 是替代渠道。

## B. 隐私合规检查单（2026 标准，逐条对标）

| 项 | 现状 | 缺口 | 动作 |
|---|---|---|---|
| 本地优先声明 | ✅ 天生本地优先（记忆/画像/日记全本地） | 无声明文档 | 写 `docs/隐私说明.md`：哪些数据只在本地、哪些会发往用户配置的 API（模型调用） |
| **屏幕监控披露** | 一起看/陪玩在采样屏幕 | **高敏感：必须有显式披露** | 首次启用 watch-screen 时弹一次知情确认（本地 dialog，记 localStorage） |
| 数据导出 | ❌ | 标配 | `大肥鱼.cmd export`：打包 data+config 到 zip |
| 数据删除 | ❌ | 标配 | `大肥鱼.cmd purge`：清记忆/画像/日记（分项可选） |
| 情绪敏感数据 | 记忆库含情绪内容 | GDPR/CCPA 或触发敏感数据规则 | 隐私说明中单独列「情绪与陪伴数据」条目 + 删除权 |
| 年龄门 | ❌ | 伴侣类应用趋严 | 首次启动年龄确认（本地，一行 dialog） |
| 崩溃/更新 | 手动重启/手动打包 | 商业级需要 | 便携版加版本号+更新说明页；崩溃日志已有（console→宿主桥） |

## C. 科研级评估协议（RealCompanion 式纵向评测——我们 80% 的仪表已经在跑）

| RealCompanion 式指标 | 我们的对应仪表 | 缺口 |
|---|---|---|
| 长期关系质量（27k 消息/120 天） | 陪伴时长统计（companion-health）+ 对话历史 | 缺**纵向导出**：按周聚合出 JSON |
| 人设一致性 | persona-guard TtFD + 24h 漂移次数（doctor 已有） | 已达标——**这是我们论文级卖点** |
| 安全性 | 关怀哨兵 + parasocial 审查（九类风险） | 已达标 |
| 记忆质量 | 巩固日志 + 忠实性抽查（未做） | 把「原话→库内条目」并排导出 |
| 情绪连贯性 | PAD 总线 + 情绪弧线 | 缺量化：情绪弧线周期性导出 |
| 主动性质量 | 打分器统计（新增） | 打分分布导出（憋住 vs 开口比例） |

**行动**：`doctor export-metrics`——把上述仪表聚合成 `data/评估指标.json`（纯本地，一次聚合），
科研级就差这一步：指标全在跑，只是没有汇总出口。
