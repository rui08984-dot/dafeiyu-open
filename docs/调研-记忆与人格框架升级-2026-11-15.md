# 调研 · 记忆与人格框架升级（2026-11-15）

> 目的：判断我们现在的记忆/人格/日常框架「到底处在什么水平」，以及**值得抄什么、明确不做什么**。
> 方法：两个只读调研代理并行检索（arXiv / GitHub / 项目文档），对照我们的真实实现评估。
> 结论已落地一项（事实有效期），其余按优先级排队。

---

## 一、记忆：工程完成度高，学术先进度停在 2023

**定位**：我们是三篇工作的手工工程化版 ——
[Generative Agents 2304.03442](https://arxiv.org/abs/2304.03442)（recency×importance×relevance）、
[MemoryBank 2305.10250](https://arxiv.org/abs/2305.10250)（遗忘曲线）、
[MemGPT 2310.08560](https://arxiv.org/abs/2310.08560)（core/archival 分层）。
完成度高于多数开源 demo（多源写入、门控、三道闸、注入预算都有），但**先进度停在 2023**。

| 维度 | 我们的位置 | 是否瓶颈 |
|---|---|---|
| 分词 | bigram + IDF + 单字兜底 | **不是**（上 jieba 收益≈0，别做） |
| 向量 | 主链为零（MemOS 有 Qdrant 但服务停着） | **是**（第二大） |
| 重排 | 无 | 次要，先别做 |
| 时序 / 事实更新 | 只有日期头，无 valid_to | **是，第一大** |
| 巩固 | 纯规则 + 相似度去重，无 LLM 归并 | **是**（第三大） |
| 评测 | 无回归集 | 是「测量」不是「能力」 |

**最痛的不是「找不到」，而是「找到两条互相矛盾的事实，模型不知道哪条还算数」。**

### 值得抄的 8 个（抄机制，不抄栈）

| 候选 | 一句话 | 我们怎么用 |
|---|---|---|
| Zep/Graphiti [2501.13956](https://arxiv.org/abs/2501.13956) | 双时态知识图谱，冲突即失效旧边 | **只抄 valid_to + supersedes，不装图库** ✅ 已落地 |
| Mem0 [2504.19413](https://arxiv.org/abs/2504.19413) | LLM 抽取后 ADD/UPDATE/DELETE/NOOP 四路合并 | 补我们缺的 UPDATE ✅ 已落地（裁决层） |
| MIRIX-2.0 [2611.12068](https://arxiv.org/abs/2611.12068) | 六类记忆 + **巩固不改写原记录** | 抄这条原则 |
| MemoryOS [2506.06326](https://arxiv.org/abs/2506.06326) | 短/中/长三级 + FIFO 晋升 + heat | 分层晋升（我们有雏形） |
| Memobase | profile 与 event timeline 两等公民 | 抄 schema，不装两个服务 |
| CraniMem [2603.15642](https://arxiv.org/abs/2603.15642) | 有界缓冲 + 定时巩固 + 效用剪枝 | 空闲巩固的骨架 |
| sleep-time [2504.13171](https://arxiv.org/abs/2504.13171) | 空闲时预算前置，测试时省 ~5× | 同理 |
| MemoryBank | 艾宾浩斯衰减 | 已有规则版 |

**只读不装**：HippoRAG / StructRAG / LightRAG / GraphRAG —— 900 条规模下索引成本 > 收益；
2026 年系统级研究结论是「局部增量维护 > 全局重组」。

### 两条反直觉但有数据的发现
1. [MemTrace 2606.17328](https://arxiv.org/abs/2606.17328)：系统失败时，证据「本来能检索到」是「根本没存」的 **10 倍** —— 瓶颈常在**用证据**（注入格式、冲突处理），不在检索。
2. Mem0：图记忆只比 base 高约 2%，但 90% 的 token/延迟节省来自「抽取+合并」本身。

### 三步路线（按收益/风险/工程量）
1. **混合召回**：词法 + bge-m3 向量，RRF 融合（1–2 天，风险低）。验证：60 条中文改写查询，recall@3 ≥85%、p95 ≤300ms。
2. **写入闸 + 事实有效期**（✅ 最小切片已落地，见下）；完整版再加「只让稳定事实落库」。
3. **空闲巩固**：聚类未巩固轮次 → episode 卡片 + 事实层更新 + 归档原文；单轮注入 ≤1.5k token。

### 明确不做
装 Neo4j/Graphiti 全量图、GraphRAG、HippoRAG；把 MemOS 放回主写入路径（72–120s/条 + 曾静默丢数据）；为 LoCoMo/LongMemEval 刷分改架构；上分词器；再加第 7 套存储格式（现有 6 套应收敛为 `对话历史.jsonl` + `用户事实.json` + `episodes.jsonl`）。

### 评测建议
基准（LoCoMo / LongMemEval-S / MemBench / MemoryAgentBench / PersonaMem-v2）**只校准不日常跑**；
最高性价比是**自建 60 题真实探针**（用我们自己的日志：换工作/搬家/换猫名/上周看什么）。

## 二、人格扮演：Prompted Persona + 外挂状态 + 规则宪法

**定位**：对应「角色扮演智能体 / persona consistency / 混合主动对话」。工程化人格，不是认知架构。
差距在**度量与状态架构**：规则测不了价值观/软事实/关系轨迹；无 OOC 率、无身份探针；
10 字状态 6h 过期但**没有慢变层**；情绪只有 1D mood、无 appraisal；主动性有闸无预算；节律只有钟点。

### 值得抄的 8 个

| 候选 | 一句话 | 成本 / 补什么 |
|---|---|---|
| [Prompting Against Persona Drift 2609.24532](https://arxiv.org/abs/2609.24532) | 监测/干预分离；**行为级具体纠正降漂移 87%**，重注入只 35–38% | 每 10 轮 1 次判官；补「哨兵只泛化提醒」 |
| [Spotting OOC 2506.19352](https://arxiv.org/abs/2506.19352) | 原子级拆解言行，测对齐/一致性 | 判官+评分表；补「规则无语义粒度」 |
| [ANCHOR 2607.28818](https://arxiv.org/abs/2607.28818) | 分开测「人格扮演」与「轨迹记忆」 | 离线 20–30 题；补「没测过几个月后还是不是她」 |
| [PAIR 2610.07523](https://arxiv.org/abs/2610.07523) | appraisal 事件→评价→VAD | 3 个字段；补「mood 没有为什么」 |
| [Ask Less, Ask Better 2610.24411](https://arxiv.org/abs/2610.24411) | 打断预算 1–3 次 + 注意力成本；限预算降成本 36–73% 且保留 86–94% 收益 | 预算+日志；补「没有烦不烦的量化」 |
| [Pro-Memory 2611.05731](https://arxiv.org/abs/2611.05731) | 分离「记住未来意图」与「何时执行」 | `待办意图.json`；补「主动只对时钟反应」 |
| [ZifaMem 2607.17564](https://arxiv.org/abs/2607.17564) | 摘要+情景+合并用户模型；**额外情绪状态机无可测增益** | 借 schema；别堆情绪机器 |
| [Graphing Everyday 2608.09294](https://arxiv.org/abs/2608.09294) | 从叙事抽作息做 JITAI；日程可用 ≠ 心理可接受 | 轻量版=学活跃时段 |

### 评测（四层，全低成本）
- 规则层（免费）：OOC 命中率、TtFD、长度/列点/客服腔/自称 AI 比例
- 文风层：20–30 句基准句 embedding 质心，余弦距离 + 句长/语气词分布
- 判官层：每 10 轮 6 维 rubric（身份/价值观/边界/文风/关系/记忆）→ 0/1/2 + 证据；**换模型判**避免自评
- 探针层：20 个固定身份/轨迹问题，新会话与长会话后各问一次
- 「烦不烦」直接看日志：主动条数/日、90 秒回复率、被打断率、「别说了」率、夜间条数；
  `烦人指数 = 忽略率×条数 + 负面率×3`，按周看

### 三件事（若要做）
1. **一致性：规则哨兵 → 原子 OOC + 行为级纠正**（1–2 天，收益最高）：每 10 轮异步判官，输出 `{dimension, quote, fix}`，命中注入「你刚才说了 X，下一句改成 Y」。先修三处：字数口径 70/200/161 统一、`self-ai` 放行自嘲、dynamic-persona 只转述真实状态。
2. **主动性：打断预算 + 结果反馈 + 未来意图**（1 天）：日预算（如 6 条）、每来源成本、90 秒后记 accepted/ignored/negative 并按接受率调成本。
3. **慢人格：core / slow / fast 三层**（2–3 天）：core 不可自动改；slow 需 ≥2 个不同日期证据、周更 ≤5 条；fast 是现在的 10 字状态。

### 明确不做
多用户 A/B、RLHF/DPO 训练、日常跑全量 benchmark、重型 PAD/appraisal 状态机（ZifaMem 证明无增益、PAIR 的 arousal 难测）、自适应干预时机、第二套记忆。

## 三、本轮已落地（最小切片）

**事实有效期**（`js/core/user-facts.js` + memory-recall 接线）：
- `用户事实.json`：`{id, fact, valid_from, valid_to, supersedes[], superseded_by, source, confidence}`
- 新事实与有效事实**几乎一字不差** → 纯规则直接取代；其余（换猫名这类）→ **一次很小的 LLM 裁决**（UPDATE/ADD）
- 只有 `valid_to` 为空的事实进注入索引；历史走 `recall action=facts include_expired=true`
- 裁决失败/离线 → **保守不压**（宁可并存也不误删）
- 真机验证：`gamma-03` → `delta-04` 后旧的失效、新的有效、supersedes/superseded_by 都对
- 回归 20 条（纯规则边界 / UPDATE / ADD / 裁决失败 / 索引集成 / 单字查询兜底）

**顺手修掉两个真实链路才暴露的 bug**：
1. 裁决抛错会连**新事实都不写**（整条丢）→ 现在裁决失败也照写（并存）
2. `用户记忆.json` 里有重复内容会**提前 return，事实层根本不跑** → 现在重复时也跑一遍幂等的事实写入

## 四、下一步建议（等拍板）

| 优先级 | 事 | 为什么 |
|---|---|---|
| 1 | **混合召回**（词法 + 向量 RRF） | 唯一能同时提升「找得到」和「找得准」的一步；1–2 天 |
| 2 | **自建 60 题真实探针** | 没有它，后面所有改动都是凭手感 |
| 3 | **人格：原子 OOC + 行为级纠正** | 论文实测降漂移 87%，比现在的泛化提醒强一个量级 |
| 4 | **主动性：打断预算 + 结果反馈** | 直接决定「烦不烦」，且能立刻量化 |

不建议现在做：episode 巩固（要等召回和探针先就位）、慢人格三层（收益慢、改动大）。
