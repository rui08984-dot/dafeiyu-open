# 大肥鱼数字同事 · 实施计划（能抄就抄版）

## 目标与成功判据

**目标：** 一个能装进本机 DSH、装上就活、并且能长期用的 Live2D 桌宠插件。

**验收（全部要肉眼可见）：**
1. DSH 插件页出现「大肥鱼桌宠」卡片，启用后桌面出现透明置顶窗（420×525）。
2. 宠物会呼吸、眨眼、随机小动作；点空白处能穿透到下面的应用。
3. 发起一个 DSH 任务：**思考→干活→等审批→完成/报错**，宠物各有不同表情与动作。
4. 它说话时**嘴型跟着真实音量**动，说完归零；字幕气泡同步出现。
5. 没有鼻部黑块；连续跑 30 分钟不崩、不卡、不掉帧到 10 以下。

**架构：** 直接以 GHOST CE（Apache-2.0）为骨架——它已经实现了「任意 Live2D 模型 + 真实 PCM 包络口型 + 情绪表情 + 透明窗/覆盖层双形态」。我们只补三件事：**TTS 来源**（抄 dsh-pet 的 edge-tts 宿主实现）、**状态桥**（抄 dsh-pet 的 session/event→6 档）、**资产与安装**（抄 GHOST 安装器 + 我们已验证的皮套构建）。

**技术栈：** Node 24 / TypeScript / Electron 28（GHOST 自带）/ pixi.js 7.4.3 + pixi-live2d-display 0.5.0-beta + Cubism Core 5（均已锁定哈希）

**Spec：** `docs/specs/2026-10-30-大肥鱼桌宠-design.md`

## 三、任务分解（每个都有可跑的验收）

### 任务 1：资产落位（30 分钟）
- 新建 `models/dafeiyu/`，把 `皮套-大肥鱼公皮/model/` 拷入并全部改 ASCII 名（`大肥鱼.moc3 → dafeiyu.moc3` 等），同步改 `model3.json` 里的 `FileReferences`。
- 新建 `live2d.manifest.json`：`{"name":"大肥鱼","hiddenParts":["Part46"]}`（Part46 = 鼻子，黑块根因，已实测定位）。
- **验收：** `node -e` 校验 model3.json 引用的每个文件都存在；用 GHOST 的 dev 页加载，截图无黑块。

### 任务 2：vendor + 构建（20 分钟）
- 运行 `node scripts/fetch-vendor.mjs --accept-live2d-eula`（哈希与锁定值一致，无需改锁）。
- 运行 `node scripts/build-all.mjs` 产出 `packages/plugin/lib/client.js` / `lib/window.js`。
- **验收：** 生成的两个文件存在且 > 1 MB；`node --check` 通过。

### 任务 3：宿主 TTS（抄 dsh-pet，1 小时）
- 从 dsh-pet 复制 `voice/{edge,cache,speak,voices}.ts` → 合并成 `src/host/tts-edge.ts`，去掉依赖 DSH 的部分。
- 在 GHOST 已有的 HTTP 路由表里加一条 `GET /tts?text=&voice=`（返回 `audio/mpeg` + 缓存）。
- **验收：** `curl -o a.mp3 "http://127.0.0.1:34567/tts?text=你好"` 拿到可播放 mp3；重复请求命中缓存。

### 任务 4：说话与口型（1.5 小时）
- 客户端新增 `speak(text)`：fetch mp3 → `decodeAudioData` → `BufferSource + AnalyserNode` → 每帧 `stage.pushEnvelope([rms])`，结束 `stage.speakEnd()`。
- 调 `attackTau=0.03 / releaseTau=0.07`（GHOST 默认值，够用）。
- **验收：** 触发一次说话，嘴型随音量起伏，说完 200 ms 内归零；录屏对比音频波形。

### 任务 5：状态桥（抄 dsh-pet，2 小时）
- 复制 `work-status.ts` + `session-watch.ts` → `src/host/state.ts`：`session/event` → 6 档（thinking/working/waiting/success/error/idle）。
- 在状态变化时，通过 GHOST 已有的 `/command` 通道推 `setEmotion(<情绪名>)`。
- 情绪映射写进 `models/dafeiyu/emotion-map.json`（thinking→思考, working→专注, waiting→期待/催促, success→开心, error→抱歉/沮丧）。
- **验收：** 在 DSH 里跑一个任务，观察 6 档切换时表情确实变化（截图 5 张）。

### 任务 6：安装（1 小时）
- 抄 `install.ps1` → `tools/install-pet.ps1`：向 profile 写三个 `link:` 依赖 + `dsh.profile.bundles` 追加 bundle；备份原文件。
- 对 `desktop` 与 `web` 两个 profile 都装（或先只装 `desktop`）。
- **验收：** 重启 DSH 桌面端 → 插件页出现卡片 → 启用 → 桌面出现宠物。

### 任务 7：打磨到"完美"（2 小时）
- 窗口 420×525、右下角、置顶、点击穿透（抄 dsh-dafeiyu 的三层 pointer-events 策略）。
- 气泡字幕接 `speak` 文本（抄 dsh-pet 单槽气泡）。
- 性能：`fps=30 / idleFps=15 / devicePixelRatioCap=1 / antialias=false`（GHOST 默认已符合）。
- **验收：** 30 分钟连续使用无崩溃；CPU 占用 < 10%；点击穿透验证（点宠物背后的按钮有效）。

## 五、风险与预案

| 风险 | 概率 | 预案 |
|---|---|---|
| pixi-live2d-display **0.5.0-beta** + Core5 + moc3 v5 组合有问题 | 中 | **任务 1 结束立刻验证**；失败则换我们已实测的 pixi6+0.4.0（`皮套-大肥鱼公皮/` 里那份 bundle.js 是证据），只把 GHOST 的 envelope/emotion 逻辑移植过来 |
| GHOST 的 `/command` 通道语义与状态推送不匹配 | 中 | 读 `src/client/index.js` 的 SSE 处理，按它支持的命令格式发；必要时加一条 `emotion` 命令 |
| DSH 插件需审批而本会话审批被禁用 | 高 | 不走 `plugin_manager`，用安装脚本直接写 profile（GHOST 就是这么装的） |
| 桌面端与 web 端 profile 各自加载，装错一侧看不见 | 中 | 两个都装；或先用 `web` profile 验证再装 `desktop` |
| 模型太大导致首次加载 3–5 秒 | 低 | 2048 纹理已降到 5 MB；moc3 16.5 MB 属正常，加 loading 状态 |
