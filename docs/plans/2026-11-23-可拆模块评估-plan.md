# 还有哪些模块适合独立公开 · 评估方案 v1

> 日期：2026-11-23 · 状态：**待拍板，未执行**

> 评分：独立性/复用价值 1–5；许可风险、数据边界 低/中/高。所有测试数字为实测断言数。

## 逐项依据

**1. 派活执行层**（`petbridge/dispatch-ledger|runner|verify|dsh-dispatch.mjs` + `js/core/dispatch-followup-policy|dispatch-retry-policy.js`）
- 仅 Node 内置模块；411 断言全过（96+162+47+106）。
- 但 `dispatch-runner.mjs` 硬编码 `<user-home>/.../DeepSeek Harness` 并读 `~/.dsh/.credentials.yaml` → 公开前必须参数化；测试有 16 处宿主路径。
- 与 control 仓的 dispatch 插件重叠 → **合并进 control**，不新建仓。
- ⚠ 现有 `_release/dafeiyu-control/tests/test-dispatch-v2-p1.cjs` 实测已坏（`ERR_MODULE_NOT_FOUND: host/live-2d/petbridge`），合并时一并修。

**2. mind-kernel**（`plugins/community/mind-kernel/`）
- lib/ 三层纯逻辑 940 行；wrapper 依赖 5 个宿主模块；350 断言全过。
- `dafeiyu-memory/NOTICE` 已把它标为自有 MIT → **不新拆第三仓**，只核对同步。

**3. 语音四态/打断**（`js/core/voice-intent.js`、`interrupt-event.js`、`heard-text.js`）
- 403 行、**零 require、不碰 DOM/IO**（测试自证），纯中文判定；104 断言全过（58+46）。
- 不依赖 TTS 引擎/模型 → 通用「语音通道状态机」，最适合独立公开。
- **建议新建 `dafeiyu-voice`（公开）**：3 文件 + 测试 + README + MIT + 中文使用说明。

**4. 插件运行时**（`plugin-context|plugin-manager|plugin-base|passthrough-policy.js`）
- 1824 行，但需 16 个宿主模块才能编译；195 断言依赖宿主。
- 上游 `morettt/my-neuro` 有同名文件（MIT，Copyright (c) 2025 xxxiu），本版约 2 倍体量属实质改写 → **必须保留上游署名**；且项目 package.json 写 ISC 与 MIT 冲突，先修许可声明。
- **结论：暂不公开**（独立性 2 分，拆出去也跑不起来）。

**5. 记忆工具链**（`memos-backup`、`memos-consistency`、`rename-self-identity`）
- 1471 行，150 断言全过；数据边界**高**（导出/改写真实记忆）。
- 前两者已在 `dafeiyu-memory`；`rename-self-identity` 会批量改身份称呼 → **永不出公开仓**。
- 结论：并入 memory（保持私有），不新拆。

**6. 控制中心/能力注册表**（`control-main|control-preload|control-v2-renderer|capabilities.js`）
- 6630 行；依赖 9 个宿主模块 + 硬编码服务表（1000/8103/8003/.control-token）；数据高（读写含 key 的配置与记忆图谱）。
- 上游派生（control-main 78KB→159KB）；211 断言但只能静态审源码。
- 结论：暂不公开。`capabilities.js`（362 行、零依赖）可单拆并入 control，但 audit 上溯 5 层找 impl 需改为可配。

## 建议执行顺序（拍板后）

1. **`dafeiyu-voice` 新建公开仓**（0.5–1 天）：3 文件 + 104 断言 + MIT + README（中文，含接入示例）。风险最低、复用最高。
2. **派活层并入 `dafeiyu-control`**（1–2 天）：同步 v2 插件、参数化 DSH 路径、修坏测试、补 NOTICE。
3. **`capabilities.js` 并入 control**（0.5 天）：上溯路径改成可配参数。
4. 其余不动（mind-kernel/memory 保持私有；插件运行时/控制中心暂不公开）。
