## 关键更正：那个 0.5B 是 3D 的

`live-2d/plugins/community/body-actions/metadata.json`：

- displayName: 身体动作插件 v1.2.0
- description: 让 AI 在回复中用 [英文单动作] 控制 VRM 或 PMX 身体
- download_dlc: https://www.modelscope.cn/models/morelle/T2M-DLC2

- T2M 是独立 HTTP 服务（默认 127.0.0.1:17880，/api/health、/api/generate），输入英文动作描述，输出关节坐标，再由插件重定向到 VRM/PMX 骨骼。
- 它驱动不了 Live2D：Live2D 没有骨骼，只有 509 参数 + 131 组物理。
- my-neuro 里 Live2D 的自主动作其实是 `js/avatar/live2d/param-director.js`（规则 + 编舞，不是神经网络）。
- 版本线索：v6.8 文本动作插件(vrm/pmx) → v6.8.1 T2M 插件模型升级 → v6.8.2 优化文本动作同步；v6.7.5 曾暂时禁止皮套肢体系统（影响对话体验，回应变长）。

结论：GPU 留给 TTS/ASR；Live2D 走动作导演路线（LLM 输出 [英文动作] 标签 → 翻译成参数编舞）。真想用 T2M 全部能力，得换 3D 皮套。
