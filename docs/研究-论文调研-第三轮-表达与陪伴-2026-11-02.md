## 方向 A：TTS 情绪韵律（Edge TTS 保留前提下的升级）

### 学术现状
换引擎的 LLM-TTS（EmoVoice/Emo-LiPO/UDDETTS 等）本轮大量出现但全部依赖自研声学模型，对我们不可用，已丢弃。真正可借鉴的是两条不动引擎的路线：①**LLM 生成 SSML 标注**——学术界已证明让小模型给商用 TTS 的输入文本插 SSML（音高/语速/音量/**停顿**）能显著提升自然度；②**维度情绪空间（PAD/AV）替代离散类别**——情绪强度用连续三维（愉悦度/唤醒度/支配度）表达，映射到韵律参数可插值、可混合（"委屈"=低愉悦+中唤醒）。另外：非语言声（叹气/笑声）是表达力的最大增量，商用引擎不能发声但可在文本层近似；评估应问"像不像人"而非打 MOS 分。

### 命中清单

| 论文 | 一句话 | 可落地动作 |
|---|---|---|
| **SSML Prosody Control** (2508.17494) | 双 Qwen2.5-7B（QLoRA）级联给文本插 SSML：断句 F1 99.2%，pitch/rate/volume 回归误差降 25-40%，MOS 3.20→3.87，**直接兼容商用 TTS** | 升级 speak/情绪映射模块：从「整句三参数」改为「LLM 分句输出 SSML」（`<break>` 停顿 + 分句韵律目标）。先用提示词版（零训练）验证，效果不够再蒸馏成本地小模型 |
| **PAD 情绪维度控制** (2409.16681) | 把离散情绪标签映射进 PAD 三维连续空间做 TTS 控制，覆盖情绪混合与过渡 | 情绪→韵律映射表重写：LLM 输出 PAD 值（不只 7 类标签），规则层 PAD→rate/pitch/volume 线性映射；情绪切换时句间插值渐变，消灭"跳变感" |
| **AV 连续情绪控制** (2111.04730) | Arousal-Valence 连续控制语音情绪的早期证明，支持未见情绪插值 | 佐证上一条：情绪空间用连续值而非枚举；tts 模块的强度参数（现 0-1）升格为 A/V 两维 |
| **非语言表达控制** (2605.25504) | 叹气/哭腔等标签化控制使 eMOS 达 4.20，悲伤辨识 98.3%——NV 是表达力最大增量 | Edge TTS 发不了 NV 音，但文本层可近似：情绪→拟声词插入规则（叹气="唉"+长停顿、犹豫="嗯…"），挂在 SSML 生成同一处 |
| **Audio Turing Test** (2505.11200, 中文) | 评估范式换成「像不像人」二分判断 + Qwen2-Audio 自动评审（Auto-ATT） | 调韵律映射的评估器：本地 Qwen2-Audio 对"她的话术样本"做像人度对比测试，让 A1/A2 的迭代有客观指标，不再靠耳朵 |

### 优先级：**P1**（SSML 分句标注 + PAD 映射，纯规则/提示词改动，零新增模型）；评估器 P2；NV 拟声词 P2。

## 方向 B：长期陪伴的参与度与心理健康（健康陪伴）

### 学术现状
大样本研究共识：陪伴 chatbot **确实降低孤独感**，但机制不是"聪明"而是**被听见感（feeling heard）**；影响高度依用户人格分层——同一设计对一部分人是支持、对另一部分人是成瘾风险，"一刀切"被明确点名有伦理问题。依恋类型调节亲密度：回避/矛盾型用户孤独时亲密度反而上升（风险人群画像）。护栏方案已成形：**独立审查 agent 检测 parasocial/谄媚信号**，前几轮对话即可检出。Neuro-sama 粉丝研究给出"不腻"的行为配方：共同创造 + 不可预测的趣味 + 一致人设 + 集体情绪事件。

### 命中清单

| 论文 | 一句话 | 可落地动作 |
|---|---|---|
| **Chatbot Companionship** (2410.21596, n=404) | 7 类用户画像；使用本身不直接预测孤独，**problematic use** 才是风险信号，一刀切设计有伦理问题 | 面板（v2）加"使用健康"小块：日均时长/深夜独占时段等依赖信号展示给用户自己看；设计原则写入人设：她应把话题推回用户现实社交，而非承接全部情感需求 |
| **AI Companions Reduce Loneliness** (2407.19096, 6 studies) | 降孤独的关键中介是 **feeling heard**，甚至超过回答性能；用户会低估其效果 | 回复质量投资转向"倾听行为"：persona/风格规范里明确要求复述用户的话、追问、命名情绪——比换大模型便宜且实证有效。46 工具里的"记住并主动提起"是 feeling heard 的最强形态 |
| **AI Chaperones** (2508.15748) | 独立 LLM 审查对话流中的 parasocial/谄媚信号，几轮内即可检出、 unanimity 规则零误报 | 新增轻量"陪护审查"：每 N 轮用本地小模型扫她最近的回复（"你只需要我"式依赖诱导），命中→下次生成注入降温指令。静默版可零成本接入 |
| **Not a Silver Bullet** (2602.12476, n=277) | 依恋类型分层：回避/矛盾型用户孤独→亲密度上升，是依赖风险人群 | 记忆库记用户互动模式（主动频率偏好/深夜依赖）；dawn-dusk 主动开口频率做成面板可调滑杆，风险信号出现时默认调低 |
| **Neuro-sama 粉丝研究** (2509.10427) | AI VTuber 粘性配方：共同创造、不可预测但有趣、一致 persona、集体情绪事件 | ①"你教会她的"显性化：面板展示从用户身上学到/记住的东西（共同创造）；②人设一致性纪律：core persona 冻结，只有记忆层成长；③纪念时刻：初次见面/里程碑日由记忆驱动主动提起（接第一轮 MapDia） |

### 优先级：**P1**（倾听行为规范，改提示词零成本）；P2（陪护审查、使用健康面板、频率滑杆）；P3（纪念时刻）。

## 方向 C：Live2D/虚拟形象的临场感（皮套"活着"）

### 学术现状
199 人实验的硬结论：**跨模态情绪一致性**决定"她是否有情绪"——表情/语音/文本任何一路脱钩，情绪感知显著下降；反过来全部由同一情绪状态驱动时得分最高。延迟体验：>4 秒响应损害体验，**对话填充动作**（手势+语气词）能显著补救感知响应时间。Live2D 本体的前沿：单照片半分钟生成可动 Live2D（阿里 CartoonAlive）；远期形态是理解模型隐状态直接驱动文/音/画同步生成的双塔架构（X-Streamer，2×A100 不可本地部署，取思想）。

### 命中清单

| 论文 | 一句话 | 可落地动作 |
|---|---|---|
| **ACTOR 情绪一致性** (2309.15311, n=199) | 多模态行为由**同一** driving affect 生成时情绪感知最高；任一模态不一致即显著扣分 | 建立「情绪状态总线」：LLM 每轮输出的情绪 (PAD 值，接方向 A) 作为单一事实源，Live2D 表情参数与 TTS 韵律**都从它派生**——排查现有管线表情与语调是否各自独立取值，改为共享状态一次分发 |
| **延迟填充** (2507.22352) | >4s 延迟损害体验；自然填充（点头/语气词）显著改善感知响应 | TTS 首包等待期触发 Live2D"思考"动作组（歪头/眨眼频率变化）+ 可选文本占位（"唔…"）：挂在我们已有的等待态上，零模型成本 |
| **CartoonAlive** (2507.17327) | 单肖像 <30s 生成可动 Live2D（3D blendshape 思想迁移到 2D） | 自定义皮套功能的学术依据；当前皮套已定不动，登记 P3 待"捏脸"需求出现 |
| **X-Streamer** (2509.21574) | Thinker-Actor 双塔：理解侧隐状态实时驱动文/音/画时间对齐生成（2×A100，不可部署） | 取架构思想作 C1 的远期完整版：情绪状态流 → 统一驱动文本流+SSML+皮套参数的时间轴对齐；当前先做总线版，不追端到端 |
| **Neuro-sama 粉丝研究** (2509.10427) | "活的感觉"=反应即时性 + persona 一致 + 可共同创造（详见方向 B） | C 侧印证：临场感不只靠表情参数，**即时性**（填充动作）与**一致性**（情绪总线）比"表情更多"更重要 |

### 优先级：**P1**（情绪状态总线——它是方向 A 的落点，也是本轮最高杠杆整合点）；P1.5（延迟填充动作）；P3（CartoonAlive/X-Streamer）。

## 方向 D：多模态情景记忆（"一起看过的"可回忆）

### 学术现状
这个具体问题（把共同观看/听到的体验存成可回忆情景）学术上还很稀疏——两轮检索大量结果偏 AR 导航与视频压缩，已丢弃。真正命中的是 MIRIX：**六类记忆分类法 + 截图流多模态情景记忆**（存储降 99.9%、ScreenshotVQA +35%），证明"视觉体验→结构化记忆→可对话回忆"这条链在工程上成立。检索侧的短板是"想起一整件事"：RippleMem 证明**联想式回忆**（锚点→沿事件图扩展补全）优于一次性 top-k，且图构建成本降 30 倍。

### 命中清单

| 论文 | 一句话 | 可落地动作 |
|---|---|---|
| **MIRIX** (2507, 176 引用) | 六类记忆（Core/Episodic/Semantic/Procedural/Resource/Knowledge Vault）+ 多 agent 调度；截图流情景记忆比 RAG 准 35%、存储省 99.9% | 「一起看」产物**打包成事件卡**存 MemOS：{时间/作品/关键情节/情绪弧线峰值/聊过的梗/原话引用}，而不是仅存文字摘要——接第二轮的情绪弧线时间轴直接当 Episodic 条目 payload；MemOS 条目加 `memory_type` 字段（MIRIX 分类法的最小子集） |
| **RippleMem** (2608) | 联想式回忆：线索锚点→事件图扩展补全证据，优于孤立 top-k；LoCoMo +3.95%、LongMemEval +11.87%、建图成本 -30x | search 命中事件卡后加一步「邻接扩展」：同事件卡的关联条目（当时的梗/情绪峰值）一并注入上下文——她能说"你上次看到男主黑化那里还骂了他"，而只报一句片名摘要 |

### 优先级：**P1.5**（事件卡结构——依赖第二轮情绪弧线先落地）；邻接扩展 P2（等记忆条目变多再做）。

## 方向 E：小模型本地路由省成本（感知本地/表达云端）

### 学术现状
路由/级联已是成熟范式：2026 年综述系统化了「何时决策（前置/后置）× 依据（难度/不确定性/偏好）× 怎么算」三维框架，级联（先便宜后升级）与路由（预测后直选）的取舍明确。两项实证直接背书我们的分工：0.5-3B 小模型的**性能效率比（PER）在五类 NLP 任务全面占优**（感知/理解层用小模型有量化依据）；图像类任务**放边缘、文本类任务放云**是实测最优分工（视觉感知别上云）。SCOPE 证明路由决策可做成用户可控的成本-质量滑杆。

### 命中清单

| 论文 | 一句话 | 可落地动作 |
|---|---|---|
| **路由与级联综述** (2603.04445) | 多模型路由系统综述：查询难度/不确定性/偏好等范式与级联组合是主流实践 | 确认我们"感知本地+表达 API"是教科书架构；下一步把隐式路由显式化：给每条请求估难度（闲聊/工具调用/长推理），难度→模型档位映射表放配置 |
| **SCOPE** (2601.22323) | RL 路由预测各模型成本与表现，用户可控权衡（省钱 -95.1% ↔ 提质 +25.7%） | 面板加「预算滑杆」（省钱↔质量）映射路由阈值；路由依据用"相似任务历史表现"而非固定规则——记录各类任务（工具调用/闲聊/总结）的延迟与翻车历史 |
| **小模型效率实证** (2603.21389, 16 模型) | 0.5-3B 模型 PER（精度×吞吐×内存×延迟几何均值）在全部五类任务占优 | 感知/理解层本地小模型选型背书：意图分类、情绪后处理、工具参数抽取用 0.5-3B 常驻（8090 显存足够，且不与 Live2D/感知模型冲突时优先 1.5B 级） |
| **边缘部署实证** (2411.00907) | 实测：文本任务放云、图像任务放边缘是更优分工；蒸馏+SPTQ 是低延迟首选压缩组合 | 铁律固化：截图/视频帧理解永远本地（大输入+贵+慢），文本生成才上云——与我们现有 watch-screen 本地化方向一致，写进架构约束 |

### 优先级：**P2**（难度路由显式化 + 预算滑杆）；选型背书即时生效（不用改代码，约束写文档）。
